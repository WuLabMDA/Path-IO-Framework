# UNI Tissue Habitat Map Generation

This module postprocesses the patch-level eight-class predictions generated by the Path-IO UNI inference module. When a matching slide-level GeoJSON contour is available, non-background patches overlapping the contour by **less than 1%** are reassigned to **Background** (class `0`). If no valid contour is available, the original tissue predictions are retained. The module then creates a color-coded habitat map and exports a copy named `<slide>.png`.

## Requirements

Python 3.9+ with `numpy`, `pandas`, `shapely>=2.0`, `scikit-image`, and `tqdm`.

```bash
pip install numpy pandas 'shapely>=2.0' scikit-image tqdm
```

## Input structure

Prediction CSV files may be nested in slide folders:

```text
UNI_predictions/
  SlideA/SlideA_prediction_256.csv
  SlideB/SlideB_prediction_256.csv
contours_geojson/
  SlideA.geojson
  SlideB.geojson
```

Each CSV must contain `x`, `y`, `patch_size`, `x_idx`, `y_idx`, and `pred`. `pred` is an integer in `[0, 7]`. The `x`, `y`, and `patch_size` values must be in **the same coordinate system as the GeoJSON geometries**, typically level-0 WSI pixel coordinates. `x_idx` and `y_idx` indicate the patch-grid position. Contours are expected as GeoJSON FeatureCollections with a `features` array.

## Run with GeoJSON contours

```bash
python generate_habitat_maps.py \
  --csv-root /path/to/UNI_predictions \
  --geo-root /path/to/contours_geojson \
  --output /path/to/UNI_postprocessed \
  --final-maps /path/to/UNI_final_maps \
  --threshold 0.01 \
  --chunk-size 5000 \
  --workers 16
```

`--geo-root` is optional. Without it, maps are generated directly from UNI predictions (no contour filtering). Use `--overwrite` to regenerate existing outputs.

## Outputs

```text
UNI_postprocessed/
  SlideA_prediction_geo_01pct.csv
  SlideA_map_geo_01pct.png
  geojson_postprocessing_summary.csv
UNI_final_maps/
  SlideA.png
```

The postprocessed CSV retains original prediction columns and adds `geo_overlap`, `pred_post`, `pred_class_post`, `geo_used`, `geo_coverage`, and `postprocess_reason`. The summary reports patch counts, contour coverage, whether contours were used, and the number of non-background patches reassigned to background.

**Map resolution:** each image pixel corresponds to one patch-grid cell; the PNG is not a full-resolution WSI. The palette and tissue class order are identical to the UNI classifier:

| Index | Tissue class | RGB |
|---|---|---|
| 0 | Background | 54, 54, 54 |
| 1 | Bronchi | 251, 217, 204 |
| 2 | Inflammatory | 41, 150, 191 |
| 3 | Lung | 1, 0, 128 |
| 4 | Necrosis | 142, 142, 142 |
| 5 | Stroma | 71, 169, 45 |
| 6 | Tumor | 229, 76, 37 |
| 7 | Vessel | 187, 47, 154 |

**Notes:** The output naming retains `_01pct` for compatibility with the original pipeline, even if `--threshold` is changed. GeoJSON overlaps are only calculated for originally non-background patches; original background patches have `geo_overlap=0` when a contour is used. If a slide fails, the error is reported in the summary. The script does not generate tissue contours; they must be supplied separately.
